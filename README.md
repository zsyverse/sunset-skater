# 落日滑板社 V4 / Sunset Skate Club

原创海岸主题 2D 横版滑板 H5 游戏。三条可直接选择的路线：落日海岸（900 m）、橘子小镇（1,050 m）、蓝调山路（1,200 m）。

## 本地运行

在此目录执行 `npm start`，浏览器打开 http://127.0.0.1:5187 。只需 Node.js，无需安装依赖。所有游戏资源均在 `dist/` 中，不依赖在线 CDN。

## 操作

- 自动向右滑行；按住空格或上方向键蓄力，松开起跳。轻点小跳，长按高跳。空中不能再次跳跃。
- 手机上按住右下角「跳跃」按钮，松开跳跃；也可点击游戏画面。
- 按住 ↓ / S 或触屏「滑行」键压低身体，穿过横杆和低枝；完全通过后松开。下蹲不能躲过地面障碍。
- 从上方落到薄荷绿栏杆上自动滑杆，可越过连续箱阵；滑到底额外得分，也可再次起跳离开栏杆。
- P / Esc 暂停或继续，R 重新开始当前路线。
- 点击音符开关音效，点击全屏图标进入全屏。手机可横屏游玩。
- 每条路线两个检查点。摔倒后从检查点重试，星星恢复到检查点的数量，避免重复刷分。
- 连续通过障碍积累连击，得分倍率最高 5 倍；摔倒连击归零。检查点同时恢复星星、得分与通过记录。
- 通关后记录该路线最高分和最高星数；记录仅存本机浏览器，存储不可用时仍可游玩。
- 页面失焦、切换到后台、打开操作说明时自动暂停。

## 结构

- `dist/engine.js`：固定步长的地形、跳跃、碰撞、收集、检查点和通关逻辑。
- `dist/art.js`：原创程序绘制场景与关节动画，包括海岸、棕榈、城镇、蓝调山路。
- `dist/game.js`：Phaser 场景、输入、页面状态、音效和本地记录。
- `dist/vendor/phaser.min.js`：本地打包的 Phaser 3.90.0，MIT 许可。
- `dist/index.html` / `dist/style.css`：响应式界面和触控操作。

## V4：动态障碍与刹车

第 4–8 关各加入 260 m 动态机关段：

- 来回滚动的轮胎：观察位置后起跳，不能靠下蹲避开。
- 摆锤：摆过站立高度，低头滑过，或刹车等它摆开。
- 升降闸门：红灯闭合、绿灯通行、黄灯即将关闭。按住 ← / A 或屏幕「刹车」键停车等待，松开后逐渐恢复速度。闸门下不要起跳。

刹车只影响地面速度，空中与栏杆上保持水平速度；暂停、取消触控和重试会释放刹车。动态障碍的渲染与碰撞共用相同位置计算，暂停时机关停止；检查点记录游戏时间，重试恢复同一机关节奏。音乐与已有跳跃、滑行、滑杆继续保留。

当前路线长度分别为 900、1,050、1,200、1,640、1,720、1,860、1,860、2,220 m。

32 项测试通过，包括全部 8 关的完整操作回放、停车/加速、空中不可刹车、闸门开闭碰撞、轮胎与摆锤姿态判定、四种起跑时间下的动态机关通过性，以及检查点机关时间恢复。浏览器实际检查了刹车等待绿灯、松开通行与起跳躲轮胎，未出现新的控制台错误。实体手机尚未测试。

## V11 · 完整的游戏流程

- **关卡解锁**：通关第 N 关解锁第 N+1 关。未解锁的地图可以预览，卡片变灰并标注解锁条件，出发按钮锁定。
- **每日挑战**：按日期生成一条 24 段的随机路线，同一天所有人的路线相同。场景从 8 个世界里轮换，速度从 340 逐渐加到 410。没有检查点，摔倒即结束，记录今日最佳和历史最远距离。通关第 8 关后，结算页会直接带你去每日挑战。
- **出发倒计时**：开局显示 3-2-1-GO，检查点重试时显示 READY。倒计时期间不能暂停，操作提示等到 GO 再弹出。

## V13 · 试玩打磨

用无头 Chrome 在 1280×800、1440×900、手机竖屏 390×844、横屏 844×390 / 667×375 下实际试玩后修的问题：

- **新手引导**：第 1 关通关前，第一次遇到路锥、横杆、断崖、栏杆时进入慢动作（0.35 倍），屏幕中间提示该按什么键。提示分「准备」和「现在！」两步，「现在」按真实跳跃弧线计算（轻跳要在路锥前 34–139 px 起跳）。做对就恢复正常速度，摔倒后重试会再教一次。
- **起跳缓冲**：落地、上杆或碰到光环前 0.15 秒内按下跳跃不再被吞掉。一直按住的话，落地后立即开始蓄力。在上升气流里按住仍然只是上升。
- **摔倒提示对应原因**：普通断崖、宽断崖、断桥（滑杆）、换杆、跳环、加速带、弹簧、高墙、高箱子、箱阵各有自己的提示。以前困难关卡掉进任何坑都会提示「借助栏杆」。
- **开局自动把游戏区滚进视野**：1280×800 下游戏区原本从 527 px 开始，按空格开局时大半在屏幕外。

- **结算卡**：5 项数据排成一行，桌面端不再需要滚动才能看到「重玩」。小屏自动压缩。成就和新解锁的地图（例如通关第 3 关后的「第 4 关」「第二季」）直接显示在结算卡里，不再用横幅盖住卡片。滑行中的成就横幅移到连击计数下方。

## V14 · 画面流畅度与清晰度

- **去掉 Phaser 的 60 fps 限帧**：`fps.limit:60` 会累积帧间隔，不足 16.667 ms 就整帧跳过。60 Hz 屏幕的帧间隔约 16.666 ms，结果大量帧被跳过，游戏实际以约 30–44 fps 更新，画面一顿一顿；120 Hz 屏幕只能每 3 帧更新一次，约 40 fps。现在每次浏览器刷新都更新：60 Hz 下每帧固定 2 个物理步，120 Hz 下 1 步。物理累加器带 0.1 ms 容差，浮点误差不会再造成「这帧 1 步、下帧 3 步」。
- **渲染插值**：物理仍按 1/120 s 固定步长推进，绘制时把滑手位置插值到最近两步之间。新手引导的 0.35 倍慢动作原来约 1/3 的帧完全不动，现在每帧位移均匀；90 / 144 Hz 屏幕同样受益。
- **高分屏清晰度**：画面直接画到游戏画布上，不再先画进纹理再整屏拷贝一次。画布按设备像素渲染，最多 2 倍，Retina Mac 和手机上角色、文字和线条不再发虚。如果设备持续低于约 38 fps 超过 2.5 秒，会自动降到 1 倍并保持。
